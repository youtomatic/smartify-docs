## Description

The right light. Always.

Bright for the morning. Warm for the evening. The Dimmer learns when you want a room to feel different — and adjusts without you asking. Fits behind your existing switch. Works with your existing lights.

A single-channel Zigbee phase-cut dimmer module designed to retrofit any standard wall switch with intelligent brightness control — no switch replacement required.

Supports trailing and leading edge phase-cut dimming up to 200W for compatible dimmable lighting fixtures and drivers. Installs behind the existing switch in a flush box or on DIN rail. Communicates natively over Zigbee 3.0 with Home Assistant, and integrates with Matter and Apple HomeKit via a compatible hub.

## Installation

### Requirements
- Existing wall switch in a flush box (≥ 60mm depth recommended)
- Live, Neutral, and Load wires in the flush box
- Zigbee coordinator within range

<Steps>
<Step>
**Turn off the circuit breaker** for the affected circuit.
</Step>
<Step>
Remove the existing switch plate. The retrofit module sits *behind* the existing switch — no visible hardware change.
</Step>
<Step>
Connect wiring:
- **Live** → L input
- **Neutral** → N input
- **Load** → load output(s)
</Step>
<Step>
Fit the module into the flush box. Use DIN rail adapters for panel board installation.
</Step>
<Step>
Replace the switch plate.
</Step>
<Step>
Restore power. The device will blink — ready to pair.
</Step>
<Step>
Pair with your Zigbee coordinator.
</Step>
</Steps>

### Load Limits
- Dimmable loads only (resistive and leading-edge phase-cut compatible).
- Not suitable for ceiling fans or non-dimmable drivers.
- Max load: 200W.
